# 식당 꾸미기 슬롯 설계 (2026-11-12, 1차, 사용자 확인 대기)

사용자 요청(11-12): 수납장 안, 접시, 화분 같은 꾸미기 요소와 테이블 종류, 주방 용품, 화구까지 상점에서 사서 등록하면 화면에 보이게 한다.
그래서 식당 배경은 건물 구조만 남긴 **빈 바탕** 위에 물건 그림을 칸(슬롯)마다 얹는 방식으로 바꾼다.

  - 남은 것: 지붕, 들보, 벽, 왼쪽 창, 오른쪽 입구 문, 종이 등 2개, 줄전구, 간판 판, 후드 2개, 빈 벽 선반 판, 가운데 빈 찬장, 빈 조리 카운터 2개, 마루
  - 빠진 것(모두 슬롯 물건이 됨): U자 바, 화구, 냄비와 도구통, 선반 위 그릇과 양념병과 화분, 찬장 속 물건
- 물건이 다 놓인 모습(기본 세트 예시): 같은 폴더 `bg_shop_openkitchen_day_4차_수납장.png`, `night_2차_수납장.png`
- 설계도: 같은 폴더 `설계도_슬롯_1차.jpg`(SD 1.3배 올림), `설계도_슬롯_1차_SD없음.jpg`
- 뒷벽 가운데 통로는 쓸모가 없어 찬장으로 바꿨다(사용자 11-12)

## SD 크기
- 바에 비해 SD가 작아 보인다는 의견(사용자 11-12). 1.0, 1.3, 1.5배를 비교해 **1.3배(서 있는 키 195px, 앉은 손님 배율 0.339 x 1.3 = 0.44)** 를 추천. 1.5배는 왼쪽 첫째 줄 손님이 주방과 겹친다
- 코드: `GuestSD.SEAT_SCALE`, 서 있는 SD 높이(STAFF_H 등), `SEAT_LIFT`도 1.3배

## 그 밖의 자리 (슬롯 아님)
- 걷는 통로: x 0.388~0.613, y 0.431~0.694. 지금 코드의 FLOOR_MIN.y 0.40은 새 카운터와 겹치니 **0.431**로
- 완성 접시 내놓는 자리(`pass`): 찬장 앞 낮은 나무턱 (0.506, 0.422). 지금 코드 PASS (0.51, 0.37)에서 바뀐다
- 요리사(세라) 자리: 화구 뒤, 발끝 y 약 0.413. 요리사를 그린 뒤 카운터 덮개(왼쪽 x 0.187~0.408, 오른쪽 x 0.592~0.813, y 0.375~0.432)를 빈 바탕에서 잘라 다시 덮는다. 그 위에 화구와 용품 슬롯을 그린다
- 그리는 순서(뒤에서 앞): 빈 바탕 → 선반, 찬장 물건 → 요리사 → 카운터 덮개 → 화구, 용품 → 테이블(바) → 바 위 소품 → 의자 → 손님, 알바, 주인공(y 순) → 화분

## 물건 그림 받는 법
- 칸마다 설계도의 상자를 노란 테두리로 표시한 확인 그림을 첨부해, 그 칸 크기와 시점(정면에서 약 25도 내려다봄)에 맞는 투명 PNG로 받는다
- 테이블은 U자 바 한 덩어리로 받는다(941x1671 캔버스 그대로, 바 밖은 투명). 종류가 바뀌어도 바 윗면과 통로 위치는 같아야 손님과 통로 좌표가 그대로 맞는다
- 같은 종류 물건은 한 장에 여러 개 받아 `tools/slice_sheet.py`로 자른다
