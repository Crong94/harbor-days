## 테이블 폭과 SD 크기
- 사용자(11-12): SD에 비해 테이블이 너무 크다. 두 가지를 함께 적용한 안:
  - SD 1.3배(서 있는 키 195px, 앉은 손님 배율 0.339 x 1.3 = 0.44). `GuestSD.SEAT_SCALE`, 서 있는 SD 높이, `SEAT_LIFT` 모두 1.3배
  - 테이블 폭 70% (사용자 11-12 확정, 100/70/60/50% 비교 뒤): 바 안쪽 가장자리(걷는 통로)는 그대로 두고 바깥 가장자리만 안쪽으로. 앞 바 깊이도 70%. 손님 자리는 바 가장자리를 따라 안으로 옮김(아래 표 `chair_*`, 코드 SEATS도 이 값으로)

## 그 밖의 자리
- 걷는 통로: x 0.388~0.613, y 0.431~0.694. 지금 코드의 FLOOR_MIN.y 0.40은 새 카운터와 겹치니 **0.431**로
- 완성 접시 내놓는 자리(`pass`): 찬장 앞 낮은 나무턱 (0.506, 0.423). 지금 코드 PASS (0.51, 0.37)에서 바뀐다
- 요리사(세라) 자리: 화구 뒤, 발끝 y 약 0.412. 요리사를 그린 뒤 카운터 덮개(왼쪽 x 0.191~0.410, 오른쪽 x 0.590~0.810, y 0.373~0.432)를 빈 바탕에서 잘라 다시 덮고, 그 위에 화구와 용품
- 그리는 순서(뒤에서 앞): 빈 바탕 → 벽지, 바닥 → 후드, 선반, 찬장 물건, 간판, 등, 줄전구 → 요리사 → 카운터 덮개 → 화구, 용품 → 테이블 → 바 위 소품 → 의자 → 손님, 알바, 주인공(y 순) → 화분
- 첫째 줄 손님(chair_0, chair_4)은 주방 카운터 바로 앞이라 머리가 카운터와 겹쳐 보인다. 답답하면 양옆 줄 전체를 y +0.02 내린다

## 물건 그림 받는 법
- 칸마다 설계도의 상자를 노란 테두리로 표시한 확인 그림을 첨부해, 그 칸 크기와 시점(정면에서 약 25도 내려다봄)에 맞는 투명 PNG로 받는다
- 테이블, 바닥, 벽지, 줄전구는 941x1671 캔버스 그대로(물건 밖은 투명) 받는다. 종류가 바뀌어도 테이블 안쪽 가장자리는 같아야 통로와 자리 좌표가 그대로 맞는다
- 같은 종류 물건은 한 장에 여러 개 받아 `tools/slice_sheet.py`로 자른다
- 기본 세트(처음부터 있는 물건)는 지금 수납장 판의 모습을 따른다
