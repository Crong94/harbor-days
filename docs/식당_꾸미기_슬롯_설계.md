# 식당 꾸미기 슬롯 설계 (2026-11-12, 7차)

사용자 요청(11-12): 수납장 안, 접시, 화분 같은 꾸미기 요소와 테이블, 주방 용품, 화구, 후드, 벽지, 바닥, 간판, 조명까지 상점에서 사서 등록하면 화면에 보인다. 식당 배경은 건물 구조만 남긴 **빈 바탕** 위에 물건 그림을 칸(슬롯)마다 얹는다.

## 배치 (사용자 스케치 11-12)
- 뒷벽 (사용자 11-12, 7차): 위, 아래 선반 모두 벽 끝까지(진열 칸 8개). 후드 둘은 천장에 딱 붙게 흰 타일 벽 위 나무 벽에 단다(짧은 후드 그림). 간판은 줄 없이 그 사이 벽 맨 위 가운데. 5~6차의 가운데 위 선반, 굴뚝 긴 후드는 어색해서 쓰지 않는다
- 조리대 둘: 뒷벽에서 앞으로 내놓음. 왼쪽 조리대는 왼쪽 벽부터, 오른쪽 조리대는 오른쪽 벽까지. 가운데는 트여서 안쪽 통로와 이어진다. 조리대마다 화구 칸 하나
- 요리사(세라): 뒷벽과 조리대 사이 타일 바닥에 서서 손님 쪽을 본다(지금 앞모습 조리 시트 그대로)
- U자 바: 폭 70%, 지난 판보다 165px(0.099) 아래. 조리대와 바 사이를 조금 띄움
- 손님: 양옆 줄은 모두 바 바깥 가장자리에서 같은 거리(50px), 앞 바 두 자리는 가로 0.39, 0.61로 가운데에 붙임
- SD 1.3배(서 있는 키 195px, 앉은 손님 배율 0.44)

## 그림 (git에는 없고 드라이브 art_inbox/2026-11-12)
- 빈 바탕: **3차**를 쓴다(`bg_shop_openkitchen_day_빈바탕_3차.png`, `night_빈바탕_3차.png`, 드라이브 `_empty3.png`). 4차(위 선반 가운데만)는 쓰지 않는다
