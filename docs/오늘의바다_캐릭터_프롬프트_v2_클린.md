# 오늘의 바다 : 이미지 프롬프트 v2 (클린 트렌디 화풍)

수채화풍 대신 **요즘 코지 생활 게임 트렌드에 맞춘 깔끔한 2D 일러스트**로 방향을 바꾼다. 이 문서가 화풍 기준이며 이전 프롬프트 문서(`오늘의바다_캐릭터_프롬프트.md`)의 수채화 관련 내용은 더 이상 쓰지 않는다.

## 화풍 기준

| 항목 | 기준 |
|---|---|
| 선 | 깔끔하고 얇은 선. 검정 대신 진한 색의 컬러 라인 |
| 채색 | 부드러운 셀 채색 2단 그림자, 은은한 그라데이션, 가장자리 림라이트 |
| 색감 | 맑고 산뜻한 색. 바다 청록, 새벽 남보라와 복숭아빛, 포인트 빨간 등대 |
| 분위기 | 따뜻하고 편안한 코지 생활 게임 |
| 캐릭터 | 시안 B 얼굴 + 옅은 수염. 33세, 순하고 살짝 지친 인상, 눈 뜬 잔잔한 미소 |
| 피할 것 | 수채화 번짐, 거친 붓 터치, 과한 채도, 사진 같은 질감, 화면 속 글자 |

## 고정 캐릭터 설정
짧고 살짝 덥수룩한 검은 머리, 물 빠진 남색 버킷햇, 얇은 은테 둥근 안경, 옅은 수염, 빛바랜 남색 집업 바람막이(소매 걷음), 크림색 티셔츠, 목에 흰 수건, 카키 카고 바지, 짙은 초록 장화. 하늘색 아이스박스 손잡이에 빛바랜 사원증 줄.

## 공통 네거티브 (Midjourney `--no` 또는 Stable Diffusion)
```
watercolor, paint bleeding, rough brush strokes, photorealistic, 3d render, oversaturated, harsh black outlines, text, watermark, logo, extra fingers, deformed hands
```

**한국어**
```

33세 한국 남성. 순하고 살짝 지친 듯하지만 다정한 얼굴, 자연스러운 성인 비율. 짧고 살짝 덥수룩한 검은 머리 위에 물 빠진 남색 버킷햇, 얇은 은테 둥근 안경, 턱에 옅은 수염, 눈을 뜨고 조용히 안도하는 미소.
빛바랜 남색 집업 바람막이(소매를 걷음), 크림색 티셔츠, 목에 흰 수건, 카키 카고 바지, 짙은 초록 장화.
오래된 방파제 끝에 앉아 한 손에 낡은 스피닝 낚싯대를 쥐고, 다른 손으로 작은 볼락을 들어 올린다. 볼락은 짙은 갈색 몸에 얼룩무늬, 아주 크고 동그란 눈.
옆에는 하늘색 아이스박스, 손잡이에 빛바랜 회사 사원증 줄이 묶여 있다. 고등어 무늬 새끼 고양이가 물고기를 올려다본다.

조용하고 따뜻하며 희망찬 분위기. 화면에 글자 없음. 가로 16:9.
```
