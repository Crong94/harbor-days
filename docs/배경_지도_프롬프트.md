# 오늘의 바다 : 배경과 마을 지도 프롬프트

화풍 기준은 `오늘의바다_캐릭터_프롬프트_v2_클린.md`와 같다. 깔끔한 컬러 라인, 부드러운 셀 채색, 맑고 산뜻한 색감.

## 공통 규칙
- **그림 속 글자 금지.** 장소 이름은 게임에서 따로 얹는다
- **사람 없이.** 캐릭터는 게임에서 따로 올린다
- 크기는 16:9, 가능하면 2560 x 1440 이상
- 같은 장소의 낮과 밤은 **구도를 똑같이** 맞춘다 (첫 장을 이미지 참조로 넣고 시간대만 바꿔 달라고 요청)

## 공통 네거티브
```
text, letters, signs with writing, labels, watermark, people, characters, watercolor, paint bleeding, photorealistic, 3d render, oversaturated, harsh black outlines
```
