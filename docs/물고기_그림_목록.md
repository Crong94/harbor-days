# 물고기 그림 목록

사용자가 준 시트 12장(`docs/ref/sheets/sheet01~12.png`, 드라이브 `오늘의바다_백업/ref/sheets`)을 `tools/slice_sheet.py`로 잘라 `docs/ref/pieces/`에 둔다.

```
python3 tools/slice_sheet.py docs/ref/sheets/sheet11.png docs/ref/pieces
```

## 화풍 결정
물고기는 **시트 그림(둥근 선의 귀여운 아이콘풍)**으로 간다. 2026-11-09 사용자 결정: 세밀화 볼락이 다른 그림과 너무 이질적이라 볼락도 시트 조각으로 바꿨다. 세밀화 원본은 `docs/ref/볼락_세밀화.png`에만 남겨 둔다.

## 시트 구성 (어종 추가할 때 참고)
| 시트 | 내용 |
|---|---|
| sheet01, 02 | 생선구이 접시 (식당 메뉴용) |
| sheet03, 04 | 민물고기 |
| sheet05 | 오징어류, 쥐치, 정어리, 쏨뱅이류, 가오리, 쏠배감펭, 아귀 |
| sheet06 | 쏨뱅이, 우럭류, 삼세기, 광어, 강도다리, 대구, 조기류, 방어류, 갈치 |
| sheet07 | 벵에돔, 혹돔, 돌돔, 능성어, 붉바리 등 갯바위 어종 |
| sheet08 | 갈치 |
| sheet09 | 놀래기, 복어, 갑오징어, 문어, 주꾸미, 농어 |
| sheet10 | 노래미, 쏨뱅이, 성대, 도다리, 가자미, 망둥어류, 쥐치 |
| sheet11 | 전갱이, 방어, 숭어, 학공치, 보리멸, 조기, 우럭(10), 볼락(11) |
| sheet12 | 감성돔, 참돔, 돌돔, 벵에돔, 농어, 부시리, 삼치, 고등어 |

어종 이름은 그림을 보고 추정한 것이라, 새 어종을 넣을 때 사용자에게 한 번 확인한다.
