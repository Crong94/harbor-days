# 오늘의 바다 UI 디자인 시스템

코드: `scripts/ui/ui_kit.gd` (UiKit). 모든 화면은 여기 있는 토큰과 컴포넌트만 쓴다. 색 코드나 글자 크기를 화면 코드에 직접 쓰지 않는다.

## 방향
- **세로 모바일 720 x 1280** (PC에서는 540 x 960 창). 한 손으로 엄지가 닿는 아래쪽에 주요 버튼
- **물빛 유리 + 종이 혼합**
  - 그림 위에 뜨는 것(HUD 칩, 대사창, 지도 핀, 토스트, 상단바)은 반투명 남색 **유리**
  - 읽을 게 많은 창(카드, 상점 목록, 장부, 모달, 아래 시트)은 따뜻한 크림색 **종이**
- 주요 행동은 **산호색**, 새것과 강조는 **햇살 금색**, 정보와 좋은 수치는 **청록**
- 큰 둥근 모서리, 부드러운 그림자, 짧고 부드러운 움직임

### 글자
| 단계 | 글꼴 | 크기 | 쓰임 |
|---|---|---|---|
| display | 고운바탕 Bold | 92 | 게임 제목 |
| h1 | 고운바탕 Bold | 44 | 장면 제목, 카드 이름, 간판 |
| h2 | Pretendard Bold | 30 | 창 제목 |
| title | Pretendard SemiBold | 23 | 목록 항목 이름, 이름표 |
| body | Pretendard Medium | 21 | 대사, 설명 |
| label | Pretendard SemiBold | 17 | 칩, 작은 버튼, 배지 |
| caption | Pretendard Regular | 15 | 도움말, 보조 정보 |

`UiKit.text("글자", "h2", UiKit.INK)`처럼 쓴다. 글꼴은 `assets/fonts` (Pretendard 5굵기, 고운바탕 2굵기, 모두 OFL)

### 모양과 움직임
- 반경: `RADIUS_SM 10`, `RADIUS_MD 16`, `RADIUS_LG 24`, `RADIUS_PILL`
- 간격: `SPACE_XS 4`, `SM 8`, `MD 12`, `LG 20`, `XL 32`
- 그림자: `elevate(스타일, 1~3)` 1은 버튼과 칩, 2는 창, 3은 모달과 카드
- 움직임: `MOTION_FAST 0.14`, `BASE 0.24`, `SLOW 0.45`초. `fade_in`, `rise_in`(아래에서 떠오름), `pop_in`(튕기며 나타남)

## 컴포넌트
| 함수 | 설명 |
|---|---|
| `action(글자, kind, small)` | 버튼. kind: `primary` 산호, `secondary` 종이, `glass` 그림 위, `ghost` 글자만. 마우스를 올리면 살짝 커지고 누르면 눌린다. 포커스는 금색 테두리 |
| `paper_panel()` / `glass_panel()` | 종이, 유리 패널 |
| `inset_box()` | 종이 안쪽 칸 스타일 (목록 한 줄) |
| `chip(이름, 값, 아이콘)` | HUD 칩. `set_chip(칩, 값)`으로 값만 바꾼다 |
| `badge(글자, 배경, 글자색)` | 작은 배지 (새로운 물고기, 사용 중, 능력치) |
| `line_edit(...)` | 채워진 입력창. 포커스 때 산호 테두리 |
| `draw_bar(캔버스, 영역, 값, 색, 유리 위, 표시 구간)` | 둥근 게이지 (장력, 힘, 간, 굽기) |
| `scrim()` | 모달 뒤 어두운 막 |
| `cover_art(id)` | 배경 그림을 화면 가득 |
| `shade([[위치, 투명도], ...])` | 그림 위 글자를 읽기 쉽게 하는 위아래 그러데이션 |
| `icon_rect(id)` | 아이콘 그림. 그림이 아직 없으면 자리를 차지하지 않는다 |
| `DialogueBox` | 유리 대사창 + 산호 이름표. 지문은 이름표 없이 흐린 글자 |
| `ArtSlot` | 그림 자리. `cover = true`면 꽉 채운다. 그림이 없으면 옅은 칸에 이름 |

## 화면 배치 원칙
- 위: 유리 상단바나 칩 (장소, 시각, 잔고). 위에서 20~24px
- 가운데: 그림과 주인공
- 아래: 대사창, 아래 시트, 주요 버튼 (엄지 자리). 양옆 12~36px 여백
- 모달: 어두운 막 위 가운데 종이 카드, 버튼은 카드 아래쪽 꽉 차게
- 같은 화면에서 산호 버튼은 하나만 (가장 중요한 행동)

## 그림이 필요하면
UI 코드는 직접 만들지만 그림(배경, 초상화, 아이콘, 간판)은 만들지 않는다. `docs/그림_요청_목록.md`에 적고 "이미지 N → 프롬프트 N" 순서로 프롬프트를 준다.
