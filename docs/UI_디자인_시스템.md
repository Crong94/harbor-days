# 오늘의 바다 UI 디자인 시스템

코드: `scripts/ui/ui_kit.gd` (UiKit). 모든 화면은 여기 있는 토큰과 컴포넌트만 쓴다. 색 코드나 글자 크기를 화면 코드에 직접 쓰지 않는다.

## 방향 (2026-11-09 바뀜: 물빛 유리 + 종이 → 둥글고 귀여운 코지)
- **세로 모바일 720 x 1280** (PC에서는 540 x 960 창). 한 손으로 엄지가 닿는 아래쪽에 주요 버튼
- 그림 화풍(둥근 굵은 외곽선, 단순한 면, 볼터치, 파스텔)에 UI도 맞춘다
  - 모든 상자는 **굵고 둥근 외곽선(3px) + 아래쪽만 두꺼운 입체 턱** (`chunky`). 누르면 턱이 줄며 내려앉는다
  - 색은 주인공 SD 그림에서 뽑았다: 외곽선 짙은 남보라, 벙거지 남색, 수건 크림, 줄무늬 하늘색, 볼터치 분홍
  - 그림 위에 뜨는 것(HUD 칩, 대사창, 지도 핀, 상단바)은 **남색 판**, 읽을 게 많은 창(카드, 상점, 장부, 아래 시트)은 **크림 종이**
- 주요 행동은 **산호색**, 새것과 강조는 **햇살 노랑**, 정보와 좋은 수치는 **민트**
- 제목, 버튼, 숫자는 **주아체**(둥근 손글씨풍), 본문은 Pretendard
- 판정 글자(PERFECT, NICE CAST, 지쳤다!)는 굵은 외곽선을 두른 스티커 글자로 튀어 오른다 (`outlined`)

### 글자
| 단계 | 글꼴 | 크기 | 쓰임 |
|---|---|---|---|
| display | 주아 | 96 | 게임 제목 |
| h1 | 주아 | 46 | 장면 제목, 카드 이름, 간판 |
| h2 | 주아 | 32 | 창 제목 |
| title | 주아 | 25 | 목록 항목 이름, 이름표 |
| number | 주아 | 22 | 숫자 (시계, 크기, 돈, 개수) |
| body | Pretendard Medium | 21 | 대사, 설명 |
| label | 주아 | 19 | 칩, 작은 버튼, 배지 |
| caption | Pretendard Regular | 15 | 도움말, 보조 정보 |

`UiKit.text("글자", "h2", UiKit.INK)`처럼 쓴다. 글꼴은 `assets/fonts` (주아, Pretendard 5굵기, 고운바탕 2굵기, 모두 OFL).
주아체에 없는 기호(· × 화살표 ♪ ✓)는 Pretendard Bold로 대신 그린다 (`font("cute")`가 FontVariation으로 감싼다). 고운바탕은 사직서처럼 편지 느낌이 필요한 곳에만 쓴다.

### 모양과 움직임
- 반경: `RADIUS_SM 14`, `RADIUS_MD 20`, `RADIUS_LG 28`, `RADIUS_PILL`
- 외곽선 `OUTLINE_W 3`, 입체 턱 `LIP 5`
- 간격: `SPACE_XS 4`, `SM 8`, `MD 12`, `LG 20`, `XL 32`
- 그림자: 턱이 있어서 옅게. `elevate(스타일, 1~3)`
- 움직임: `MOTION_FAST 0.14`, `BASE 0.24`, `SLOW 0.45`초. `fade_in`, `rise_in`(아래에서 떠오름), `pop_in`(튕기며 나타남)

## 컴포넌트
| 함수 | 설명 |
|---|---|
| `chunky(배경, 반경, 여백, 턱)` | 통통한 상자 스타일. 코지 화면의 기본 |
| `action(글자, kind, small)` | 버튼. kind: `primary` 산호, `secondary` 크림, `glass` 남색, `mint`, `sun`, `ghost` 글자만. 누르면 턱이 줄어 내려앉는다 |
| `paper_panel()` / `glass_panel()` | 크림 종이, 남색 판 |
| `inset_box()` | 종이 안쪽 칸 (목록 한 줄) |
| `chip(이름, 값, 아이콘)` | HUD 칩 (남색 알약). `set_chip(칩, 값)`으로 값만 바꾼다 |
| `badge(글자, 배경, 글자색)` | 작은 배지 (희귀도, NEW, 최대 기록, 사용 중) |
| `outlined(라벨, 두께)` | 스티커 글자 외곽선 |
| `line_edit(...)` | 흰 입력창, 짙은 외곽선. 포커스 때 산호 |
| `draw_bar(캔버스, 영역, 값, 색, 남색 판 위, 표시 구간)` | 젤리 게이지 (외곽선, 위쪽 반짝임 줄) |
| `scrim()` | 모달 뒤 어두운 막 |
| `cover_art(id)` | 배경 그림을 화면 가득 |
| `shade([[위치, 투명도], ...])` | 그림 위 글자를 읽기 쉽게 하는 위아래 그러데이션 |
| `icon_rect(id)` | 아이콘 그림. 그림이 아직 없으면 자리를 차지하지 않는다 |
| `DialogueBox` | 남색 대사창 + 산호 이름표 |
| `ArtSlot` | 그림 자리. `cover = true`면 꽉 채운다. 그림이 없으면 옅은 칸에 이름 |

## 화면 배치 원칙
- 위: 남색 칩과 상단바 (장소, 시각, 잔고). 위에서 20~24px
- 가운데: 그림
- 아래: 주인공(낚시 화면), 대사창, 아래 시트, 주요 버튼 (엄지 자리). 양옆 12~36px 여백
- 낚시 화면: 안내 문구와 줄다리기 게이지는 **위쪽**에 둔다 (아래는 SD 주인공 자리). 미끼 버튼은 왼쪽 아래, 견제 버튼은 오른쪽 아래
- 모달: 어두운 막 위 가운데 크림 카드, 버튼은 카드 아래쪽 꽉 차게
- 같은 화면에서 산호 버튼은 하나만 (가장 중요한 행동)

## 그림이 필요하면
UI 코드는 직접 만들지만 그림(배경, 초상화, 아이콘, 간판)은 만들지 않는다. `docs/그림_요청_목록.md`에 적고 "이미지 N → 프롬프트 N" 순서로 프롬프트를 준다.
