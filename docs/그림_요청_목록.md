# 그림 요청 목록

게임 안의 그림과 일러스트는 직접 그려서 받는다. 코드에는 그림 자리(회색 빈칸)만 만들어 두었고, 아래 파일 이름으로 `assets/art/` 폴더에 PNG를 넣으면 자동으로 바뀐다.

## 공통 규칙

| 항목 | 기준 |
|---|---|
| 형식 | PNG |
| 배경 | 캐릭터와 물고기는 **투명 배경** |
| 화풍 | 깔끔한 2D 셀 채색 코지 게임 스타일 (`docs/오늘의바다_캐릭터_프롬프트_v2_클린.md` 참고) |
| 화면 기준 | 게임 해상도 1280 x 720. 아래 크기의 2배로 받으면 선명하다 |
| 이미지 속 글자 | 넣지 않기 (간판, 메뉴판 글씨는 게임에서 따로 얹는다) |
