# 그림 요청 목록

게임 안의 그림과 일러스트는 직접 그려서 받는다. 코드에는 그림 자리(회색 빈칸)만 만들어 두었고, 아래 파일 이름으로 `assets/art/` 폴더에 PNG를 넣으면 자동으로 바뀐다.

## 공통 규칙

| 항목 | 기준 |
|---|---|
| 형식 | PNG |
| 배경 | 캐릭터와 물고기는 **투명 배경** |
| 화풍 | 깔끔한 2D 셀 채색 코지 게임 스타일 (`docs/오늘의바다_캐릭터_프롬프트_v2_클린.md` 참고) |
| 화면 기준 | 게임 해상도 1280 x 720. 아래 크기의 2배로 받으면 선명하다 |
| 이미지 속 글자 | 넣지 않기 (간판, 메뉴판 글씨는 게임에서 따로 얹는다) |

## 바다 한 접시에서 가져온 그림 (2026-11-09)

이전 게임(바다 한 접시) APK에서 꺼내 넣었다. 새로 요청하지 않아도 된다.

| 폴더 | 내용 | 쓰이는 곳 |
|---|---|---|
| `assets/art/dish/` | 요리 50접시 (`<레시피 id>.png`, 예: `bollak-gui`) | 식당 요리 완성 화면 |
| `assets/art/cook_tool/` | 조리도구 13개 | 이후 레시피 화면 |
| `assets/art/kitchen/` | 화로, 튀김기, 냄비, 도마 | 요리 화면 (지금은 화로) |
| `assets/art/ingredient/` | 파, 마늘, 고추, 쑥 등 8개 | 이후 레시피 재료 |
| `assets/art/gear_icon/` | 장비 아이콘 23종 x 10단계 | 낚시방, 장비 창 |

- 볼락구이 그림(`dish/bollak-gui`)은 볼락이 두 마리 담겨 있다. 한 마리 접시가 필요하면 나중에 따로 요청한다
- 바다 한 접시 물고기 아이콘은 가져오지 않았다. 물고기는 사용자 시트 그림으로 통일했다 (볼락 포함)
