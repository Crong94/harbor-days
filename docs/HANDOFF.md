## 확정된 결정
- 화면은 세로. 릴과 낚싯대는 만들어 둔 10종씩 사용(새로 안 뽑음). 회사 PC는 그림 작업만
- 손님 SD 양식: 걷기 8칸 한 줄 약 3:1(2172x724). 1, 2칸 앞모습 걷기, 3, 4칸 뒷모습 걷기, 5~8칸 오른쪽 옆모습 한 걸음 주기(왼쪽은 좌우 반전). 위에서 약 20도. 반응 3종 약 3:2(1536x1024): 서 있기, 만족, 실망(아쉬움)
- 화풍: 2.5등신, 굵고 둥근 짙은 외곽선, 단순한 면, 볼터치, 파스텔 셀 채색. 기준은 확정된 박만수, 최순덕 시트. 여울 화풍(진한 음영)은 쓰지 않는다
- 박만수 = 카리스마 있는 베테랑 어부(곧은 눈썹, 또렷한 눈, 한쪽 입꼬리). 최순덕 = 인자한 할머니(초승달 눈웃음). 화난 얼굴, 졸린 얼굴, 반쯤 감긴 눈은 탈락
- 낚시 줄다리기 UI는 T2: 장력은 낚싯대 휨새와 끝 색, 물고기 위에 남은 줄 숫자와 물고기 방향 화살표(사용자는 반대로 끌기), 누르기=감기, 누른 채 좌우 끌기=버티기, 아래 판과 글자 없음. 구현은 노트북에서

- 그림은 Claude가 크롬으로 ChatGPT 프로젝트 "오늘의바다"에 직접 요청한다. 결과를 보여 주고 검토받는다. 새 디자인은 틀이나 시험본 하나로 먼저 승인받고 나머지를 진행한다

- 결과는 미리보기 이미지(체크무늬 배경)로 보여 주고, 고친 경우 전후 비교를 보여 준다

- CI(GitHub Actions)는 아낀다. 문서만 고칠 때는 커밋 메시지에 `[skip ci]`
- 쉼표 남발, 줄표(—, ㅡ) 쓰지 않기. 이름이나 방식은 후보 표에 추천 하나

## 환경 제약
- 회사 PC에는 Godot를 설치하지 않는다. 게임 실행과 코드 작업은 집 노트북
- ChatGPT 요청: 크롬(Claude in Chrome)으로 프로젝트 페이지를 열고, 파일은 숨은 file input에 file_upload로 첨부, 글은 `document.execCommand('insertText')`로 넣는다(직접 타이핑하면 한글이 깨질 때가 있음)
- ChatGPT 새 채팅 입력창에 이전 글이 남아 있을 수 있으니 넣기 전에 전부 지운다. sandbox 다운로드는 링크 대신 파일 카드의 "파일 다운로드" 버튼을 누른다(링크는 탭이 멈출 수 있음)
- ChatGPT 결과는 자주 흰색이나 검은색 불투명 배경이다. "그림은 하나도 바꾸지 말고 캐릭터 바깥 배경만 알파 0으로" 다시 요청하면 sandbox 다운로드 파일로 준다. 받은 뒤 알파 비율을 직접 확인한다(PIL)
- 드라이브 파일은 내용 교체가 안 돼서, 이전 파일 이름을 바꾸고 새로 올린다
