## 환경 제약
- ChatGPT: Chrome(Claude in Chrome)으로 프로젝트 페이지를 열고, 파일은 숨은 file input("사진 첨부")에 file_upload로, 글은 입력창에 넣고 Enter. 결과 이미지는 페이지 JS로 alt에 "생성된"이 든 큰 img의 blob을 a.download로 받는다. 대화가 길면 가상 스크롤로 옛 이미지가 DOM에서 빠지니 이미 받은 src를 기억해 새 것만 받는다
- 투명 확인(중요): "투명 배경"으로 요청해도 흰 배경이나 가짜 체크무늬로 올 때가 많다. 가장자리에서 이어진 밝은 무채색을 지우되, 팔과 몸 사이처럼 사방이 막힌 틈의 흰색은 남는다(11-11 주인공, 복자에서 발생). 받은 뒤 반드시 "불투명하면서 거의 흰 픽셀 덩어리(300px 이상)"를 PIL과 scipy로 찾아 지우거나, ChatGPT에 "그림은 바꾸지 말고 배경만 알파 0으로" 다시 요청한다
- 세 표정 묶음은 알파 세로 합이 가장 작은 열 근처(1/3, 2/3 지점 ±8%)에서 잘라 560px 안으로 줄인다
- 같은 폴더에서 개발 세션이 동시에 돈다. assets/art, docs/ref, docs/그림_요청_목록.md, 그림 정리 문서만 고친다. scripts, scenes, tests는 건드리지 않는다
