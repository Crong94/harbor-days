## 2. 플레이어 입력 시스템

### 2.1 입력 시점

이름 입력을 메뉴 화면에서 따로 받지 않고 **스토리 안에 녹인다.**

| 입력 항목 | 입력 시점 | 연출 |
|---|---|---|
| `{플레이어명}` | 프롤로그, 퇴사 서류에 서명하는 장면 | 사직서 하단 ‘성명’ 칸에 직접 이름을 적는다 |
| `{가게명}` | 챕터 1, 식당 간판을 다는 장면 | 낡은 나무판에 붓으로 가게 이름을 쓴다. 완성되면 간판이 걸리는 연출 |

### 2.2 입력 규칙

| 항목 | `{플레이어명}` | `{가게명}` |
|---|---|---|
| 글자 수 | 한글 기준 1~6자 | 한글 기준 1~10자 |
| 허용 문자 | 한글, 영문, 숫자 | 한글, 영문, 숫자, 공백 |
| 금지 | 욕설, 비속어, 공백만 입력 | 욕설, 비속어, 공백만 입력 |
| 미입력 시 기본값 | 한바다 | 오늘의 식탁 |
| 랜덤 추천 버튼 | 있음 (예: 하늘, 준, 도윤) | 있음 (예: 한 접시, 물빛식당, 갯내음) |
| 변경 가능 여부 | 불가 | 챕터 4 이후 ‘간판 새로 달기’로 1회 변경 가능 |

### 2.3 대사 처리 규칙 (개발 메모)

한국어는 받침에 따라 조사가 달라지므로 대사 템플릿에 **조사 자동 처리**가 꼭 필요하다.

```
{플레이어명|이/가}   → 준이 / 한바다가
{플레이어명|은/는}   → 준은 / 한바다는
{플레이어명|을/를}   → 준을 / 한바다를
{플레이어명|아/야}   → 준아 / 한바다야
{가게명|으로/로}     → 물빛식당으로 / 한 접시로
```

- 마지막 글자의 받침 유무로 판단 (유니코드 `(code - 0xAC00) % 28 != 0` 이면 받침 있음)
- 영문이나 숫자로 끝나는 경우 받침 없음으로 처리하거나 `(이)가` 형태로 표기
- `ㄹ` 받침 + `으로/로`는 `로`로 처리 (예: 갯마을로)

### 2.4 이름이 쓰이는 곳

- NPC 대사의 호칭 (친밀도에 따라 호칭이 바뀜)
- 식당 간판, 영수증, 메뉴판, 마을 게시판, 신문 기사
- 손님 리뷰 ("{가게명} 생선구이 진짜 맛있어요")
- 어종 도감 표지 ("{플레이어명}의 바다 기록")
- 엔딩 크레딧

1. **빚:** 매달 돌아오는 대출 상환. 생활의 압박
2. **사람:** 외지인을 경계하는 마을. 마음을 여는 과정
3. **마을:** 인구 감소로 수산시장이 문을 닫고, 마을이 통폐합될 위기

## 5. 프롤로그 : 사직서

새벽 두 시, 판교의 사무실. 장애 대응을 마친 주인공이 빈 모니터를 보고 있다.

휴대폰에 알림이 뜬다. 아버지의 기일을 알리는 캘린더 알림이다. 바빠서 올해도 성묘를 가지 못했다.

책상 서랍에서 오래된 사진 한 장을 꺼낸다. 어린 주인공이 작은 물고기를 들고 웃고 있고, 뒤에서 아버지가 쑥스럽게 웃고 있다. 배경에는 빨간 등대가 보인다.

*"그때 그 생선, 진짜 맛있었는데."*

다음 날, 주인공은 사직서를 쓴다.

> **[이름 입력]** 사직서 하단 성명 칸
>
> 성명: `__________`

팀장은 붙잡지 않는다. 동료들은 "부럽다"고 말하지만 누구도 따라 나서지 않는다.

통장 잔고를 확인한다. 생각보다 적다. 은행 창구 직원이 서류를 내민다.

> "귀농귀촌 창업 대출 승인되셨습니다, {플레이어명} 고객님. 상환은 다음 달부터 시작이에요."

부동산 앱을 뒤지다 터무니없이 싼 매물을 발견한다. **경남 물빛울포, 식당 겸 주택, 월세 협의 가능.**

사진 속 바다에 빨간 등대가 보이지만, 주인공은 그게 무슨 의미인지 아직 모른다.

## 6. 1막 : 내려오다

### 챕터 1 : 가진 것이라고는 낡은 낚싯대 하나

버스를 세 번 갈아타고 도착한 물빛울포. 정류장에는 아무도 없다. 갈매기 울음소리와 생선 비린내만 반긴다.

임대한 식당은 생각보다 더 낡았다. 의자는 다리가 흔들리고, 주방 환풍기는 돌지 않는다. 창고 구석에서 먼지 쌓인 낚싯대 하나를 발견한다. 전 주인이 두고 간 것이다.

**튜토리얼:** 청소하기, 고장 난 환풍기 고치기 (개발자 특기 첫 활용), 창고 정리

청소를 마치고 나니 간판 자리가 텅 비어 있다.

> **[가게 이름 입력]** 나무판에 붓으로 쓰기
>
> 가게 이름: `__________`

간판이 걸린다. 화면이 천천히 줌아웃되며 작은 식당과 바다가 함께 보인다.

> *"{가게명}. 오늘부터 여기가 내 자리다."*

#### 초기 상태

| 항목 | 상태 |
|---|---|
| 보유 자금 | 18만 원 |
| 대출 잔액 | 3,000만 원 (월 상환 약 55만 원) |
| 낚싯대 | 먼지 쌓인 릴찌낚싯대 (내구도 40%) |
| 릴 | 저가형 스피닝릴 |
| 채비 | 기본 찌 세트, 크릴 미끼 1봉 |
| 조리 시설 | 낡은 가스레인지 1구, 프라이팬 |
| 레시피 | 생선구이 |
| 좌석 | 테이블 4개 중 2개 사용 가능 |

### 챕터 2 : 첫 번째 손님

문을 열었지만 팔 게 없다. 시장에서 생선을 사 오기엔 돈이 부족하다. 다음 날 **새벽 다섯 시**, 주인공은 북쪽 방파제로 향한다.

**새벽 낚시 (05:00 ~ 07:00)**

- 화면 속 시간은 현실 1.2초에 1분씩 흐른다. 별이 지고 하늘이 밝아지며 해가 떠오른다
- 볼락은 어두울 때 잘 물고 날이 밝을수록 숨는다. 밝아질수록 입질이 늦어지고 볼락 비율이 줄어든다
- 첫 물고기는 반드시 **볼락**이다. 첫 물고기를 잡기 전까지는 입질 판정이 너그럽다
- 첫 물고기를 잡은 뒤 07:00이 되면 낚시가 끝나고 오늘의 기록이 나온다

**낚시 조작 (실패를 경험하게 설계)**

1. 꾹 눌러 힘 모으기 → 손을 떼서 던지기. 힘에 따라 찌가 떨어지는 거리가 달라진다
2. 찌 보기 → 톡톡 건드리는 가짜 입질에 누르면 미끼만 날아간다
3. 찌가 쑥 잠기면 바로 누르기 (챔질). 늦으면 미끼만 뺏긴다
4. 끌어올리기 → 누르면 감고 떼면 풀어 준다. 줄 장력이 끝까지 차서 버티면 줄이 끊기고, 너무 느슨하면 바늘이 빠진다
5. 몇 번의 실패 끝에 손바닥만 한 볼락 한 마리

방파제 끝에서 그 모습을 보던 노인이 혀를 찬다. 박만수다.

> 만수: "어이 서울 양반. 그 낚싯대로 고기 잡으려면 해 지겠다 싶었는데."
>
> 만수: "볼락이네. 새벽 볼락은 눈이 커서 날 밝으면 귀신같이 숨어."
>
> 만수: "해 뜨기 전에 몇 마리 더 해 봐라. ...그래도 한 마리는 잡았네."

**새벽 방파제 어종 (1단계)**

| 어종 | 크기 | 특징 |
|---|---|---|
| 볼락 | 12 ~ 24cm | 새벽에 잘 문다. 밝아지면 숨는다. 첫 물고기 |
| 망상어 | 14 ~ 26cm | 시간과 상관없이 고르게 나온다 |
| 노래미 | 15 ~ 30cm | 힘이 좋아 끌어올리기 어렵다 |

식당으로 돌아와 소금을 뿌려 굽는다. 그때 지팡이를 짚은 할머니가 들어온다. 최순덕이다.

> 순덕: "불이 켜져 있길래. 여기 문 연 거 몇 년 만이여."
>
> 순덕: "간이 좀 세네. 그래도 따뜻한 밥 먹으니 좋구먼."

첫 매출 7,000원. 순덕은 계산을 마치고 나가다 간판을 올려다본다.

> 순덕: "{가게명|이/가}라... 이름 좋네. 오래 가라고."

그날 밤, 주인공은 장부 앱에 첫 줄을 적는다.

> *매출 7,000원. 지출 4,500원. 순이익 2,500원.*

주인공은 할 말을 잃는다. 순덕이 낡은 공책 한 권을 건넨다. 아버지가 그 여름 민박집 부엌에서 적어 둔 메모다. 서툰 글씨로 생선 요리법 하나가 적혀 있다.

**최종 레시피 〈{가게명} 정식〉 해금 퀘스트**

- 아버지의 메모에 적힌 재료를 모은다 (계절 한정 어종 포함)
- 만수, 복자, 서윤에게 각각 재료의 비밀을 묻는다
- 야광충이 뜨는 여름밤, 마을 사람 모두를 {가게명}에 초대해 요리를 내놓는다

### 엔딩 : 물빛 축제

마을 축제의 밤. 방파제에 등이 걸리고, 해변에는 야광충이 핀다.

순덕이 바다를 보며 말한다.

> 순덕: "{플레이어명}, 처음 왔을 때 기억나? 생선 하나 제대로 못 잡더니."
>
> {플레이어명}: "그러게요. 제가 이렇게 살게 될 줄은 몰랐어요."
>
> 순덕: "니 아버지가 보면 좋아하겠다."

화면이 천천히 줌아웃되며 프롤로그 간판 장면과 같은 구도로 {가게명}과 바다가 보인다. 간판 아래 불빛이 환하다.

> *오늘 잡은 물고기로 내일을 살아간다.*
>
> *{가게명}의 이야기는 여기서부터 시작이다.*

#### 엔딩 분기

| 엔딩 | 조건 | 내용 |
|---|---|---|
| 🌊 물빛 엔딩 (진엔딩) | 마을 목표 5개 달성 + 주요 NPC 전원 친밀도 최고 + 대출 완납 | 마을 통합 철회. 축제가 매년 열리고 새 가족이 이사 온다. 에필로그에서 해솔이 {가게명}에서 일을 배운다 |
| 🏮 등대 엔딩 | 마을 목표 3~4개 달성 | 마을은 살아남지만 시장은 축소된다. {가게명}은 마을의 등대 같은 곳으로 남는다 |
| 🐟 어부 엔딩 | 낚시 성장 위주, 마을 목표 2개 이하 | 마을은 통합되지만 주인공은 남아 어부로 산다. 만수와 함께 순풍호를 탄다 |
| 🚌 귀경 엔딩 | 대출 3개월 이상 연체 | 주인공은 서울로 돌아간다. 마지막 장면에서 회사 모니터 옆에 고등어 사진이 놓여 있다. 이어하기로 재도전 가능 |

엔딩 후에도 플레이는 계속된다. 도감 수집, 펫 육성, 전설 어종 도전 등 엔드 콘텐츠를 즐길 수 있다.

## 10. 부가 시스템

### 10.1 경제

| 항목 | 주기 | 초기 금액 (예시) |
|---|---|---|
| 대출 원리금 | 매월 1일 | 55만 원 |
| 식당 월세 | 매월 1일 | 20만 원 |
| 공과금 | 매월 1일 | 5~10만 원 (계절 변동) |
| 미끼 | 낚시 1회 | 3천~2만 원 |
| 장비 수리 | 내구도 0 이하 | 장비별 상이 |

- 초반 3개월은 빠듯하게, 6개월 차부터 여유가 생기도록 밸런싱
- 연체 시 바로 패널티가 아니라 은행 직원의 독촉 전화 이벤트, 만수와 복자의 도움 제안 등 스토리로 완충

### 10.2 계절과 날씨

| 계절 | 대표 어종 | 이벤트 |
|---|---|---|
| 봄 | 도다리, 볼락, 주꾸미 | 귀촌 시작, 벚꽃 낚시 대회 |
| 여름 | 농어, 벵에돔, 전갱이 | 장마, 야광충, 물빛 축제 |
| 가을 | 감성돔, 갈치, 고등어, 전어 | 태풍, 전어 축제 |
| 겨울 | 학공치, 우럭, 방어, 대구 | 김장, 연말 정산, 새해 해돋이 |

날씨: 맑음, 흐림, 비, 안개, 강풍, 태풍. 강풍과 태풍에는 출항 불가. 비 오는 날은 일부 어종 입질 증가와 손님 감소.

### 10.3 마을 발전 단계

| 단계 | 변화 |
|:---:|---|
| 1 | 낡은 방파제 보수 |
| 2 | 수산시장 일부 점포 재개장 |
| 3 | 낚시방 온라인 예약 시작, 낚시 관광객 유입 |
| 4 | 민박 리모델링, 관광 지도 |
| 5 | 물빛 축제 부활 |
| 6 | 청년 귀촌 가구 입주, 마을 통합 철회 |

마을이 발전할수록 배경 그래픽이 바뀐다. 불 꺼진 가게에 불이 들어오고, 길에 사람이 늘어난다.

### 10.4 장부와 기록

주인공은 개발자답게 모든 걸 기록한다. 장부 화면은 하루를 돌아보는 감성 장치이기도 하다.

```
[ 2027. 04. 12  맑음  물때 7물 ]

잡은 고기   볼락 4, 망상어 2
판매        생선구이 6접시, 매운탕 2
매출        96,000원
지출        21,000원

오늘의 한 줄
복자 사장님이 처음으로 '맛있네'라고 하셨다.
```

마지막 줄 ‘오늘의 한 줄’은 그날 일어난 이벤트에 따라 자동으로 작성된다.

## 11. MVP 및 개발 순서

### MVP 핵심 루프

1. 사직서에 이름을 쓰고, 간판에 가게 이름을 쓴다
2. 방파제에서 낚시한다
3. 잡은 물고기를 인벤토리에 보관한다
4. 식당에서 생선구이를 만든다
5. 손님에게 판매한다
6. 번 돈으로 장비를 바꾸고 첫 달 대출을 갚는다

> 이름 입력은 구현 비용이 낮으면서 애착을 크게 높이므로 MVP에 포함한다.

## 12. 게임의 방향

이 게임은 돈을 벌어 식당을 키우는 경영 게임이면서, 동시에 한 사람이 자기 자리를 찾아가는 이야기다.

처음부터 큰 식당이나 멋진 배를 주지 않는다. 방파제에서 손바닥만 한 물고기를 잡고, 서툴게 구워서, 첫 손님에게 7,000원을 받는 순간이 충분히 의미 있어야 한다.

플레이어가 직접 지은 이름은 사직서에서 시작해 간판이 되고, 손님의 리뷰가 되고, 마지막에는 마을 사람 모두가 기억하는 요리 이름이 된다.

> **"오늘 잡은 물고기로 내일을 살아간다."**

## 13. 추가 개선 제안

### 13.1 재미와 시스템

| 제안 | 내용 | 기대 효과 |
|---|---|---|
| 남해 향토 레시피 | 도다리쑥국, 멸치쌈밥, 갈치조림, 볼락김치 같은 지역 음식을 계절 한정 메뉴로 추가 | 다른 낚시 게임과 차별화되는 한국적 정서 |
| 금지체장과 방생 | 실제 금어기·금지체장을 반영해 작은 물고기를 놓아주면 ‘바다 신뢰도’ 상승. 신뢰도가 높으면 희귀 어종 출현 | 교육적 요소와 힐링 정서 강화 |
| 단골손님 카드 | 자주 오는 손님마다 취향과 짧은 사연을 모으는 수집 요소 | 식당 영업이 반복 작업으로 느껴지지 않음 |
| 직접 짓는 메뉴 이름 | 가게명처럼 메뉴 이름도 플레이어가 지을 수 있게 | 애착 강화, 공유하고 싶은 요소 |
| 음식 사진과 SNS | 요리를 찍어 게임 속 SNS에 올리면 평판 상승. 현석이 홍보를 돕는 이벤트와 연결 | 평판 시스템을 눈에 보이게 표현 |
| 바다 청소 | 낚시터 쓰레기 줍기로 ‘바다 신뢰도’와 재료 획득 | 자연을 돌보는 테마와 연결 |
| 개발자 특기 미니게임 | 앱을 만들 때 간단한 블록 맞추기 퍼즐 | 주인공 설정을 플레이로 체감 |
| 아버지의 기억 조각 | 특정 장소에서 회상 컷이 열리는 수집 요소 (10개) | 메인 스토리 몰입, 탐험 동기 |

### 13.2 힐링 게임다운 밸런스

| 제안 | 내용 |
|---|---|
| 펫 뽑기 축소 | 힐링 장르와 뽑기는 어울리지 않는다는 반응이 많다. 펫은 교감 이벤트로 확정 획득하고, 뽑기는 펫 옷이나 꾸미기 아이템에만 쓰는 쪽을 권장 |
| 여유 모드 | 대출 상환 압박과 시간 제한을 줄인 난이도 옵션. 이야기 위주로 즐기는 사람을 위한 선택지 |
| 실패해도 이어지는 구조 | 낚시 실패, 영업 부진, 연체가 게임오버가 아니라 새 이벤트로 이어지게 설계 (v2 방향 유지) |
| 하루 길이 | 현실 시간 기준 하루 12~15분 권장. 짧은 플레이에도 하루를 마칠 수 있게 |

### 13.3 연출과 사운드

- 시간대별 바다 색 변화 (새벽 남색, 낮 청록, 노을 산호빛, 밤 야광충 파랑)
- 찌 방울 소리, 파도 소리, 갈매기, 기름에 생선 굽는 소리를 핵심 효과음으로 녹음 수준까지 신경 쓰기
- 계절마다 OST 한 곡씩, 마을 축제 곡 한 곡
- 장부 화면 ‘오늘의 한 줄’을 손글씨 폰트로 표시

### 13.4 1인 개발 범위 관리

- 3막 전체를 처음부터 만들지 말고 **‘1년 차 봄 한 계절’ 수직 슬라이스**를 먼저 완성한다 (챕터 1~3, 주민 6명, 어종 15종, 레시피 3종)
- 수직 슬라이스로 무료 데모를 내고 반응을 본 뒤 확장한다
- 주민 대사는 엑셀이나 CSV로 관리해서 코드와 분리한다 (호칭과 조사 처리 템플릿 포함)

### 13.5 개발 환경

| 항목 | 결정 |
|---|---|
| 엔진 | **Godot 4** (2D, GDScript) |
| 실행 환경 | 로컬 PC에서 개발과 빌드 |
| 버전 관리 | 로컬 Git + 외장 드라이브 또는 클라우드 백업 이중화 |
| 자동 빌드 | 초반에는 쓰지 않는다. 필요할 때 로컬에서 수동 내보내기 |
