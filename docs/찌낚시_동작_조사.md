# 찌낚시 동작 조사와 게임 반영

스피닝릴 바다 찌낚시를 기준으로 실제 동작을 정리하고, 게임에서 어떻게 표현했는지 적는다. 수치는 대부분 강좌 글과 블로그에서 나온 것이라 절대 기준은 아니다.

## 1. 실제 동작 순서

| 단계 | 실제 동작 | 핵심 수치, 주의 |
|---|---|---|
| 준비 | 오른손으로 릴 다리를 손가락 사이에 끼워 손잡이를 쥐고, 베일을 연 뒤 검지에 줄을 건다 | 찌에서 낚싯대 끝까지 줄을 조금 늘어뜨린다 |
| 백스윙 | 낚싯대를 머리 뒤로 넘긴다 | 시계로 1시 방향 (등 뒤 비스듬히 위) |
| 포워드 스윙 | 앞으로 휘두르며 검지를 놓아 줄을 내보낸다 | 10~11시 방향에서 놓는다. 휘두른 뒤 앞쪽에서 멈춘다 |
| 착수 | 찌가 떨어지기 직전 검지로 스풀을 살짝 눌러 속도를 줄인다 (페더링) | 착수 후 베일을 닫고 늘어진 여유줄을 감아 정리한다 |
| 찌 보기 | 낚싯대를 비스듬히 들고 찌를 본다 | 약 45도. 위로 챌 수 있는 높이 |
| 견제 | 흘러가는 뒷줄을 손가락으로 잡아 찌 흐름을 몇 초 멈추거나, 낚싯대를 천천히 들어 미끼를 살짝 끌어 준다 | 약 70도까지 천천히. 바닥에서 붙어 먹을 때 입질을 끌어낸다 |
| 입질 판단 | 순간적인 떨림에 채면 헛챔질. 찌가 계속 잠겨 들어갈 때 챈다 | 2~3초 계속 잠길 때. 너무 늦으면 미끼만 뺏기거나 바늘을 삼킨다 |
| 챔질 | 팔 전체로 낚싯대를 짧고 날카롭게 위로 세운다 | 45도 이상, 낚싯대 끝 30~45cm. 옆으로 휘두르거나 귀 뒤로 넘기지 않는다 |
| 챔질 직후 | 곧바로 릴을 감아 줄을 팽팽하게 유지한다 | 2~3초 안에. 느슨하면 바늘이 빠진다 |
| 파이팅 (펌핑) | 낚싯대를 천천히 세워 고기를 끌고, 숙이면서 그만큼 줄을 감는다 | 너무 낮추면 낚싯대 탄력을 잃고, 너무 높이 세우면 부러진다. 숙일 때 줄이 느슨해지면 안 된다 |
| 랜딩 | 발 앞까지 끌어온 작은 고기는 낚싯대 탄력으로 들어 올리고, 큰 고기는 뜰채로 뜬다 | |

## 2. 게임 반영

| 단계 | 게임 조작 | SD 주인공 자세 (낚싯대 높이) | 규칙 |
|---|---|---|---|
| 준비 | | 60도 | |
| 백스윙 | 꾹 누르기 | 75도 → 125도 (머리 뒤로 넘김, 힘 게이지) | 누른 시간 = 던지는 힘 |
| 포워드 스윙 | 손 떼기 | 125도 → 30도로 빠르게 휘두름 | 힘 × 낚싯대 성능 = 거리 |
| 착수 | | | 착수 직후 줄이 늘어졌다가 정리되며 팽팽해짐 |
| 찌 보기 | 기다리기 | 45도 | 찌가 조류에 옆으로 천천히 흘러감 |
| 견제 | 오른쪽 클릭 또는 Shift 누르고 있기 | 70도, 줄이 팽팽해짐 | 찌 흐름이 멈추고 입질이 빨라지며 톡톡 입질도 늘어남 |
| 입질 | | 45도 | 찌가 점점 깊이 잠겨 들어감 (1초, 첫 물고기는 1.6초) |
| 헛챔질 | 톡톡 떨릴 때 누르기 | | 실패: 찌가 살짝 떨린 순간에 챘다 |
| 챔질 | 찌가 잠길 때 누르기 | 0.2초 동안 85도로 확 세움 | |
| 파이팅 | 누르기 = 숙이며 감기, 떼기 = 세워서 버티기 | 누르면 42도, 떼면 68도. 물고기가 당기면 끌려 숙여짐 | 계속 감으면 줄이 끊어지고, 오래 안 감으면 바늘이 빠짐 |
| 랜딩 | | 82도 | 물고기가 바늘에 매달려 물 밖으로 올라온 뒤 카드가 나옴 |

뒤에서 보는 화면이라 낚싯대 높이는 원근으로 표현한다. 바다 쪽으로 누울수록 짧게, 수직일수록 길게, 머리 뒤로 넘기면 끝이 몸 쪽으로 눕는다 (`scripts/fishing/player_rig.gd`).
